## Notes
- **Company logos** load live from Clearbit (`logo.clearbit.com/<domain>`). If a
  logo is unavailable, a colored monogram badge (e.g. `CG`, `BU`) shows instead —
  both look intentional.
- Filenames are referenced in `js/main.js` (`image:` per project). Keep the names
  above and images just appear.
